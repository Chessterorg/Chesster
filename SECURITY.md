# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Chesster, including our smart contracts, backend API, and web application, very seriously.

If you discover a security vulnerability or bug in our smart contract escrow logic, backend engine, or web app, please do **NOT** open a public GitHub issue.

Instead, please report vulnerabilities via email or direct message to the repository maintainers.

### What to Include in Your Report
- A clear summary of the issue
- Steps to reproduce or proof-of-concept exploit script
- Impact analysis (e.g. smart contract funds at risk, state manipulation, unauthorized API access)

### Response Timeline
- **Acknowledgement**: Within 48 hours
- **Assessment & Fix Plan**: Within 5 business days
- **Public Disclosure**: After patch release and resolution

Thank you for helping keep Chesster secure!
